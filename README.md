# Запуски SpaceX 2006–2025: успехи, ракеты и площадки

Командный проект ознакомительной практики TOP DS. Мы собрали датасет всех запусков SpaceX из двух открытых API,
свели источники к единому формату и проанализировали динамику запусков, их успешность, ракеты и стартовые площадки.

**Стек:** Python (requests, json, csv) · Yandex DataLens · Figma

## Ключевые выводы

- **Взрывной рост.** С 31 запуска в 2021 году до 170 в 2025-м: в 5,5 раза за четыре года. Рост замедляется:
  +97% в 2022, +61% в 2023, +41% в 2024, +23% в 2025.
- **Falcon 9 почти не ошибается:** 580 успешных запусков из 583 (99,5%). Остальные неудачи приходятся
  на первые полёты Falcon 1 и испытания Starship.
- **Три площадки работают параллельно:** SLC-40 (49% запусков), SLC-4E (28%) и LC-39A (20%). С 2023 года
  к ним добавился Starbase в Техасе, откуда летает Starship.
- **Спады:** в 2011 году не было ни одного запуска, в 2019-м их было 13 против 21 годом ранее.

Подробный разбор по периодам есть в [презентации](reports/presentation.pdf).

## Данные

| Источник | Период | Запусков |
|----------|--------|---------:|
| [api.spacexdata.com](https://github.com/r-spacex/SpaceX-API) (неофициальный r/SpaceX API) | 24.03.2006 – 10.07.2022 | 171 |
| [Launch Library 2](https://thespacedevs.com/llapi) (ll.thespacedevs.com) | 11.07.2022 – 17.12.2025 | 439 |

**Почему два источника.** С r/SpaceX API удобно работать, но в 2022 году его перестали обновлять:
начиная с запуска Starlink 3-1 (11.07.2022) у запусков не указан исход, а часть запусков отсутствует.
Поэтому до первого запуска с неизвестным исходом берём данные из spacexdata, после него — из Launch Library.
Названия ракет и площадок в источниках различаются (например, `Falcon 9 Block 5` и `Falcon 9`,
`KSC LC 39A` и `Launch Complex 39A`), их привели к единому виду.

Итоговый датасет: [`data/spacex_launches_2006_2025.csv`](data/spacex_launches_2006_2025.csv)

| Поле             | Описание                                                                  |
|------------------|---------------------------------------------------------------------------|
| `date`           | дата и время старта, UTC (`YYYY-MM-DD HH:MM`)                             |
| `year`           | год запуска                                                               |
| `rocket_name`    | ракета: Falcon 1, Falcon 9, Falcon Heavy, Starship                        |
| `launchpad_name` | стартовая площадка                                                        |
| `success`        | 1 — успех, 0 — неудача (в том числе частичная)                            |
| `flight_number`  | порядковый номер запуска в датасете                                       |
| `source`         | источник записи: `spacexdata` или `launch_library`                        |

**Ограничения.** Amos-6 взорвалась на стартовом столе во время подготовки к запуску, но в источнике учтена
как неудачный запуск; мы оставили её так. Испытательные полёты Starship учтены как обычные запуски.

## Как воспроизвести

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python src/fetch_launch_library.py   # выгрузка Launch Library 2 (~5 запросов, лимит API — 15 в час)
python src/build_dataset.py          # сборка data/spacex_launches_2006_2025.csv
```

`src/fetch_spacexdata.py` выгружает данные из r/SpaceX API, но сейчас API недоступен,
поэтому результат выгрузки сохранён в `data/raw/`.
